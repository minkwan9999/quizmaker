# 영어 문제 출제기

영어 지문으로 시험 문제를 만드는 정적 웹사이트입니다. `index.html` 하나로 동작하며 GitHub Pages로 바로 배포할 수 있습니다.

## 출제 방식 (사용자가 선택)
- **AI 출제** – 주제·제목·요지·빈칸 추론·어법·어휘·내용 일치·요약문·서술형 영작. 본인의 Anthropic API 키가 필요하며, 키는 브라우저(localStorage)에만 저장됩니다.
- **지문 변형** – API 키 없이 규칙 기반으로 빈칸, 첫 글자 힌트 빈칸, 단어 배열, 글의 순서, 문장 삽입 문제를 만듭니다.
- **직접 입력** – 객관식/주관식 문항을 직접 작성합니다.

만든 문제는 하나의 시험지로 쌓이고 순서 변경·삭제, 정답/해설 보기, 인쇄(PDF), JSON 저장/불러오기를 할 수 있습니다.
